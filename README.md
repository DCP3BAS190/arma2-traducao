# arma2-traducao

Tradução não oficial para Português do Brasil (PT-BR) de:

- Arma 2
- Arma 2: Operation Arrowhead
- DLCs (ACR, PMC e BAF)

Este projeto tem como objetivo disponibilizar uma experiência mais acessível para jogadores brasileiros, traduzindo textos da interface, menus e demais conteúdos suportados pelo jogo.

## Instalação

> **⚠️ ALTAMENTE RECOMENDADO FAZER BACKUP DOS ARQUIVOS ORIGINAIS ANTES DA INSTALAÇÃO.**

1. Baixe a versão mais recente do projeto.
2. Extraia os arquivos baixados.
3. Copie os arquivos da tradução para o diretório de instalação do jogo.

### Steam

**Arma 2**
```text
C:\Program Files (x86)\Steam\steamapps\common\Arma 2
```

**Arma 2: Operation Arrowhead**
```text
C:\Program Files (x86)\Steam\steamapps\common\Arma 2 Operation Arrowhead
```

### Outras versões

Copie os arquivos para a pasta onde o jogo estiver instalado.

4. Substitua os arquivos quando solicitado.
5. Inicie o jogo normalmente.

> **Observação:** Caso você não possua as DLCs do Arma 2: Operation Arrowhead, é possível utilizar apenas a pasta `Expansion` no diretório do jogo.

## Desinstalação

### Steam

Utilize a ferramenta de verificação de integridade dos arquivos:

**Biblioteca → Página do jogo → Ícone de engrenagem → Propriedades → Arquivos Instalados → Verificar a integridade dos arquivos**

A Steam irá restaurar os arquivos originais automaticamente.

### Outras versões

Caso tenha feito backup:

1. Remova os arquivos da tradução.
2. Copie os arquivos originais do backup para o diretório do jogo.
3. Substitua os arquivos quando solicitado.
