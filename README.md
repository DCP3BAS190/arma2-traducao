# arma2-traducao

Tradução não oficial para Português do Brasil (PT-BR) de:

- Arma 2
- Arma 2: Operation Arrowhead
- DLCs(ACR, PMC e BAF)

Este projeto tem como objetivo disponibilizar uma experiência mais acessível para jogadores brasileiros, traduzindo textos da interface, menus e demais conteúdos suportados pelo jogo.

## Recursos

- Tradução para Português do Brasil
- Compatível com Arma 2 e Operation Arrowhead
- Código-fonte aberto
- Instalação simples

## Instalação
**ALTAMENTE RECOMENDAVEL FAZER O BACKUP!!**
1. Baixe a versão mais recente do projeto.
2. Extraia os arquivos.
3. Copie a pasta da tradução para o diretório de instalação do jogo.
   Pela a Steam:
   Arma 2: Program Files (x86)\Steam\steamapps\common\Arma 2
   Arma 2 OA: Program Files (x86)\Steam\steamapps\common\Arma 2 Operation Arrowhead
   Outros meios:
   Onde você tiver instalado.
5. Substitua os arquivos quando solicitado.
6. Inicie o jogo normalmente.
OBS: Caso não tenha as DLCs do Arma 2 OA, você pode usar apenas a pasta "Expansion" no diretório interno do jogo.

## Desinstalação
1. Na Steam:
Use a ferramenta de verificação de integridade que fica no seguinte caminho:
Página do jogo(Biblioteca)->Símbolo de engrenagem->Propriedades->Arquivos Instalados->Verificar a integridade dos arquivos.
2.  Caso tenha feito backup:
Substituas os arquivos manualmente no mesmo diretório
